# Knowledge base

The PDFs for this project are too large to store in this folder. You can download all of them under Assets as part of the [Knowledge Base release](https://github.com/reyD-Fly/part-107-claude-ground-school/releases/tag/knowledge-base-v1). Upload all of them to the Claude Project's knowledge as described in Step 3 of the main README file for this project.

All of these are U.S. government works produced by the Federal Aviation Administration. As such, they are in the public domain.

- **Remote Pilot – Small Unmanned Aircraft Systems Study Guide (FAA-G-8082-22)**
- **Airman Knowledge Testing Supplement for Sport Pilot, Recreational Pilot, Remote Pilot, and Private Pilot (FAA-CT-8080-2H).** These files are split into 12 separate PDFs, each designed to be within the Claude Project upload file size limit.
